<h1>Web Virtual Display<br><br></h1>
<br clear="left" />
A standalone .NET virtual display application that requires zero drivers. Simply run the app on your PC and connect any device with a web browser to use it as an additional monitor.

# Video Demo
Short demo video of my app working with multiple windows, playback, input, and typing.
![App Demo](.github/media/demo.gif)

# Installation
1: Simply download and run the binary from releases.<br>
2: Once installed and running, open the interface from the tray.<br>
3: Copy and share the URL to other devices on your LAN **OR** scan the QR Code.

# Disclaimer
This software is only supported on windows and will remain that way forever, it uses windows-only hooks and packages.
